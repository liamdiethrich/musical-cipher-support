CASE SUPPORT

Musical Cipher Support

Practical help for the native iOS app and desktop web game.

No sound?

Raise media volume, disconnect unintended audio devices, and check Text-first mode in Settings. The game respects silent or text-first play and never needs microphone access.

Progress or a locked level

Complete the current case evidence to unlock the next level. Native progress stays on that device; browser progress stays in that browser. Use Reset all case progress only when you want to erase the case.

Accessibility

Every core action has a text label and a non-drag alternative. Musical Cipher supports VoiceOver, keyboard control, larger text, reduced motion, and text-first listening.

Get help

Open a support issue with the device model, operating-system version, level number, and a short description. Never include recordings, passwords, or personal student information.
